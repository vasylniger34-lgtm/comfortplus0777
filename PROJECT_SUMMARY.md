# 🚌 Проєкт "Comfort Plus 0777" — Огляд та Історія Змін

## 🌟 Про проєкт
**Comfort Plus 0777** — це сучасна веб-платформа для бронювання пасажирських перевезень за маршрутом **Львів ↔ Східниця** (через Стебник, Трускавець та Борислав). 
Сайт поєднує преміальний дизайн, зручність мобільного додатку та потужний бекенд для надійного бронювання місць.

---

## 🛠 Технологічний стек
- **Frontend:** React + TypeScript
- **Стилізація:** Tailwind CSS + Vanilla CSS
- **Анімації:** Framer Motion (плавні переходи та мікро-взаємодії)
- **Backend & DB:** Supabase (PostgreSQL, Realtime WebSockets для чату)
- **Serverless:** Vercel Functions (вузол зв'язку з Telegram)
- **Інтеграції:** Telegram Bot API (підтримка клієнтів), html2canvas/jsPDF (генерація квитків)

---

## 🚀 Основні можливості (що реалізовано)
1. **Система Бронювання:** Вибір маршруту, дати та часу відправлення з миттєвою перевіркою ціни.
2. **Особистий Кабінет:** Реєстрація та вхід по телефону, зберігання історії поїздок, перегляд квитків та балансу.
3. **Програма Лояльності:** Автоматичний облік поїздок — кожна 20-та поїздка стає безкоштовною для користувача.
4. **Служба Підтримки (Live Chat):** Чат на сайті, інтегрований з Telegram-ботом. Адміністратор відповідає з Telegram, а клієнт отримує відповідь прямо в чат на сайті.
5. **Візуальні Квитки:** Генерація квитків у стилі посадкових талонів з можливістю завантаження у форматі PDF.
6. **Імітація Оплати:** Перевірка процесу оплати через Apple Pay / Google Pay / Картку.

## 📈 Останні оновлення (Офіційний Changelog)

### Етап 1: Міграція на Supabase Backend
- Переведено зберігання даних з `localStorage` у хмарну базу даних **Supabase**.
- Налаштовано таблиці `profiles` (користувачі), `bookings` (квитки) та `chat_messages` (історія чату).
- Реалізовано асинхронну авторизацію та захист даних користувача.

### Етап 2: Двосторонній Telegram Чат
- Створено **Telegram-бота** для підтримки.
- Реалізовано **Webhook** на Vercel, який передає відповіді адміністратора з Telegram назад у чат конкретного користувача на сайті.
- Покращено логіку бота: повідомлення про отримання запиту приходить лише 1 раз за сесію.

### Етап 3: Кабінет та Квитки 2.0
- Додано можливість **перегляду та завантаження квитків** зі списку поїздок у кабінеті.
- Реалізовано **автоматичне заповнення** форми бронювання даними авторизованого користувача.
- Введено **дискретний розклад**: система блокує вибір часу, який уже минув для поточної дати.
- Введено обмеження на скасування: кнопка "Скасувати" зникає автоматично після відправлення рейсу.
